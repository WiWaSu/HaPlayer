## Зачем

Со стримингом музыку стало легко найти и так же легко потерять. Треки пропадают из каталога, подписка дорожает, а история прослушиваний хранится на чужом сервере. Локальные плееры эту проблему решают, но большинство из них выглядит как программы из 2005 года или требует часа настройки.

HaPlayer — это удобство стриминга поверх ваших собственных файлов. Выбрали папку с музыкой, подождали пару секунд и слушаете.

## Принципы

- **Файлы остаются вашими.** HaPlayer их только читает. Сам он ничего не переименовывает, не перемещает, не удаляет и не переписывает теги.
- **Работает без интернета.** Сканирование, поиск, воспроизведение и плейлисты не требуют сети.
- **Никакой слежки.** Нет телеметрии, аналитики и рекламы. Всё, что плеер знает о вашей медиатеке, лежит в `%APPDATA%\HaPlayer`: база `library.db` (SQLite) и `settings.json`.
- **Нативное приложение.** Внутри нет Electron и WebView. Интерфейс рисует Avalonia, звук идёт через WASAPI.

Подробно всё расписано в [docs/PHILOSOPHY.md](docs/PHILOSOPHY.md).

## Возможности

Что уже работает:

- сканирование медиатеки с тегами и обложками;
- плейлисты, перемешивание, повтор;
- импорт плейлистов из Winamp;
- скачивание по прямой ссылке на аудиофайл с любого сайта (Настройки → Скачать по ссылке). Плеер берёт только то, что вы вставили, сам ничего не качает;
- торренты, по умолчанию выключены: скачивание музыки по magnet-ссылке или .torrent-файлу (из раздачи берутся только аудиофайлы и обложки) и раздача своей папки друзьям одной кнопкой. В папку, которую вы раздаёте, HaPlayer никогда ничего не записывает;
- исполнитель из папки дискографии: все песни внутри попадают к одному исполнителю, даже если в тегах написано по-разному. Файлы не меняются;
- форматы MP3, FLAC, WAV, Ogg Vorbis, AAC/M4A, WMA.

В планах:

- [ ] Opus, ALAC, APE, WavPack через FFmpeg
- [ ] bit-perfect вывод (эксклюзивный режим WASAPI)
- [ ] воспроизведение без пауз между треками (gapless)
- [ ] ReplayGain
- [ ] необязательная синхронизация между устройствами со сквозным шифрованием, без email и телефона
- [ ] сборки под macOS и Linux

## Сборка из исходников

Нужны Windows 10 или 11 и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```bash
git clone https://github.com/<user>/haplayer.git
cd haplayer
dotnet run --project src/HaPlayer
```

В IDE открывайте `HaPlayer.sln` через Visual Studio 2022 или JetBrains Rider.

## Технологии

| Часть | Библиотека |
|---|---|
| Язык | C# / .NET 9 |
| Интерфейс | [Avalonia UI](https://avaloniaui.net/) 11 |
| Вывод звука | [NAudio](https://github.com/naudio/NAudio) (WASAPI) |
| Ogg Vorbis | [NAudio.Vorbis](https://github.com/naudio/Vorbis) |
| Теги и обложки | [TagLib#](https://github.com/mono/taglib-sharp) |
| Хранение медиатеки | SQLite через Microsoft.Data.Sqlite |
| Торренты | [MonoTorrent](https://github.com/alanmcgovern/monotorrent) |
| MVVM | CommunityToolkit.Mvvm |

## Структура проекта

```
src/HaPlayer/
  Audio/        движок воспроизведения
  Library/      сканирование, теги, обложки, база SQLite, настройки
  ViewModels/   состояние интерфейса
  Views/        окна и элементы Avalonia
  Styles/       тема
assets/branding/  логотип, иконка, баннер
docs/             философия проекта
```
