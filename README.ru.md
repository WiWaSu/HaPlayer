## Скачать

`HaPlayer.exe` — на странице **Releases**. Windows 10 или 11, 64 бита. Устанавливать .NET не нужно.
Портативный zip хранит все данные рядом с программой.

## Возможности

- Медиатека из папок и файлов, теги и обложки. Повторная проверка читает только изменённые файлы.
- MP3, FLAC, WAV, Ogg Vorbis, AAC/M4A, ALAC, WMA.
- Плейлисты, «Любимые треки», очередь с «Играть следующим», перемешивание без повторов.
- Импорт плейлистов из Winamp, AIMP, VLC, Windows Media Player, iTunes.
- Страницы альбомов и исполнителей, поиск, «Сейчас играет» на всё окно.
- 10-полосный эквалайзер, выбор устройства вывода, история прослушивания.
- Интерфейс на русском и английском. Тёмная, графитовая и светлая темы, палитры, свой акцентный цвет, масштаб и шрифт.
- Мини-плеер поверх окон, медиаклавиши при свёрнутом окне, значок в трее.
- Подборки: новое в медиатеке, часто слушаю, давно не слушал. Фильтры поиска по папке, году и формату.
- Треки перетаскиваются в плейлисты и очередь. Любой список сохраняется в .m3u8.
- Вёрстка подстраивается под окно, вплоть до 640×480.
- По желанию: скачивание по прямой ссылке и торренты. Оба по умолчанию выключены.

HaPlayer не меняет ваши файлы и их теги. Его данные лежат в `%APPDATA%\HaPlayer` или рядом с программой в портативном режиме.

## Сборка

Windows 10/11 и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0):

```bash
dotnet run --project src/HaPlayer
```

`build.cmd` собирает один файл `HaPlayer.exe`.

На чём сделан: C#, [Avalonia](https://avaloniaui.net/), [NAudio](https://github.com/naudio/NAudio), [TagLib#](https://github.com/mono/taglib-sharp), SQLite, [MonoTorrent](https://github.com/alanmcgovern/monotorrent).
